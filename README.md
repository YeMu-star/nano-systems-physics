## 使用说明

- 进入课程文件夹后，`转录/原始` 是 ASR 原样 DOCX，`转录/校订` 是逐段俄语校订＋中文翻译，`重讲稿` 是 PDF。
- 原始转录不等于原音；没有音频核听，不能称“逐字还原”。
- 停课节（如 02 的第 01、03 节，03 的第 02 节）没有课堂转录，因此不在此仓库。
- 部分讲次只有转录、尚未完成重讲稿；以各课程文件夹中的实际文件为准。
